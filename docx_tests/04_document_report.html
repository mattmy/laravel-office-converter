LibreOffice HTML → DOCX Compatibility Report

版本：1.0

日期：2026-09-08

1. 測試目的

驗證以 LibreOffice Writer 將 HTML 轉換為 DOCX 時，常見文件元素是否可以維持穩定版面。

2. 測試範圍

  • 標題與段落
  • 清單
  • 表格
  • 資訊提示框
  • 分頁

3. 測試結果摘要

項目 結果
文字格式正常
表格正常
資訊區塊使用 table 後穩定

結論
若 HTML 以文書導向的結構設計，LibreOffice 轉換 DOCX 的穩定度通常會明顯優於現代網頁排版結構。
