綜合內容測試

此文件混合標題、清單、資訊框與表格，模擬一般企業系統輸出的文件內容。

執行步驟

  1. 準備 HTML 文件。
  2. 使用 LibreOffice headless 進行轉換。
  3. 開啟 DOCX 並檢查版面。
注意
文件若包含 flex、grid、absolute positioning 或複雜 CSS box model，建議先正規化為 table-based 結構。

環境資訊

項目 內容
轉換工具LibreOffice Writer
來源格式HTML
輸出格式DOCX

程式碼片段

libreoffice --headless --convert-to docx input.html
